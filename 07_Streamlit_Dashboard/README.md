# ApexMart Analytics Suite — Interactive Streamlit Dashboard

An interactive, multi-page **Streamlit + Plotly** replacement for the
Power BI dashboard suite originally specified in `04_PowerBI_Dashboard/`.
All five dashboards run from a single app, share global filters, and are
linked together through both Streamlit's native page navigation and an
in-page navigation strip on every screen.

## The Five Dashboards

| # | Dashboard | File | Audience |
|---|---|---|---|
| 1 | Executive Performance | `Home.py` | CEO & Executive Leadership |
| 2 | Sales Performance | `pages/1_Sales_Performance.py` | Sales & Merchandising Leadership |
| 3 | Store Performance | `pages/2_Store_Performance.py` | Regional / Store Operations Leadership |
| 4 | Customer Intelligence | `pages/3_Customer_Intelligence.py` | Marketing & Customer Experience Leadership |
| 5 | Inventory Optimization | `pages/4_Inventory_Optimization.py` | Supply Chain & Inventory Planning Leadership |

## How the Dashboards Are Linked

- **Shared data layer** — every page loads the same reconciled dataset via
  `utils/data_loader.py` (`@st.cache_data`), which reads `data/sales_clean.csv`
  (the output of the reconciliation pipeline in `02_SQL/` and Notebook 2 of
  `03_Python_Analysis/`) and joins it once against Customers, Products, and
  Stores. Every dashboard is therefore guaranteed to agree with the numbers
  in the written Business Consulting Report.
- **Shared global filters** — `utils/filters.render_global_filters()` renders
  the Date Range and Region controls in the sidebar on every page, storing
  the selection in `st.session_state`. Because the same `st.session_state`
  keys are reused on every page, a filter set on the Executive Dashboard is
  still applied when you click through to Sales, Store, Customer, or
  Inventory — the five dashboards behave as one connected application, not
  five disconnected scripts.
- **Cross-dashboard navigation** — `utils/filters.render_nav()` draws a
  five-item navigation strip (using `st.page_link`) at the top of every page,
  in addition to Streamlit's automatic sidebar page list, so every dashboard
  is always one click from every other dashboard.
- **Page-specific filters** — each dashboard layers its own additional
  filters (Category, Store Size, Customer Segment) on top of the shared
  global filters, scoped to that page only.

## Running Locally

```bash
cd 07_Streamlit_Dashboard
pip install -r requirements.txt
streamlit run Home.py
```

The app opens at `http://localhost:8501`. Navigate between dashboards using
either the sidebar (automatically generated by Streamlit from the `pages/`
folder) or the navigation strip at the top of each page.

> **Note on this environment:** the sandbox this project was built in has no
> outbound internet access, so `streamlit` and `plotly` could not be
> installed or runtime-tested here. Every file has been syntax-checked
> (`python -m py_compile`) and carefully written against current Streamlit
> and Plotly APIs, but please run it locally (or deploy it, below) as the
> final verification step, and let me know if anything needs adjusting.

## Deploying for Free — Streamlit Community Cloud

1. Push this folder (or the whole repository) to a GitHub repo.
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with
   GitHub, and click **New app**.
3. Point it at your repo, branch, and set the main file path to
   `07_Streamlit_Dashboard/Home.py`.
4. Streamlit Cloud installs `requirements.txt` automatically and gives you a
   public URL to share with ApexMart's leadership team.

## Data Refresh

To refresh the dashboards with new data, replace the CSVs in `data/`
(most importantly `sales_clean.csv`, which should be re-generated by rerunning
Notebook 2 in `03_Python_Analysis/` against updated raw extracts) and restart
the app — `st.cache_data` will pick up the new files on the next run.
